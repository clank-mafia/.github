**Безопасная зона.** Центрируйте аватар без увеличения, чтобы круг не обрезал латунный контур. Для другого широкого формата сохраняйте центральную область баннера x=360–1440 и y=120–470 на мастер-файле. Нижний левый край остаётся свободным от названия и слогана, если интерфейс перекрывает его аватаром. У публикаций квадратный кроп использует y=135–1215 мастер-файла. В этом диапазоне сохранены обе строки заголовка, марка и основной игровой образ. После выбора платформы проверить её собственную маску и положение интерфейсных элементов.

**Осмотр.** В круглой маске марка распознаётся при 32 и 64 px. Просмотрены баннеры 3:1 и 4:1, обе публикации 4:5 и 1:1 и уменьшенные изображения профиля. Центровая обрезка сохраняет текст, лица и главный сюжет. Экспорты проверены на целостность и фактические размеры. Изображения используют `clank-mafia-logo.svg`, `backroom-hero.jpg`, `backroom-scene.jpg` и `piece-*.webp`.

## GitHub

В публичных файлах организации на момент сверки установлены имя `Clank Mafia`, краткое описание и адрес игры. Публичный список репозиториев содержал `.github`. Доступный `profile/README.md` ссылается на игру, а баннер совпал побайтово с ранее подготовленным изображением. В этом варианте README название также повторялось внутри баннера, а один общий переход не разделял просмотр стола, создание и правила. [Организация](https://github.com/clank-mafia) · [Публичный профильный репозиторий](https://github.com/clank-mafia/.github)

[Обновлённый README](github-profile/profile/README.md) оставляет название доступным заголовком, показывает игровую иллюстрацию и даёт три прямых маршрута. Блок Build, Watch, Advance объясняет существующий игровой цикл. Далее реальный эпизод №480 с переходом к матчу. [Обложка для README 1280 × 480](github-profile/profile/assets/clank-mafia-cover.jpg) и [иллюстрация стола 1200 × 600](github-profile/profile/assets/clank-mafia-table.jpg) лежат рядом с README в готовой структуре `profile/assets/`. Иллюстрация собрана из реальных спрайтов и фона. [Запись матча №480](https://clank-mafia.vercel.app/api/tables/6b98eb8e-6142-471f-91dc-1b00e27302c3)

Публичный аватар организации при итоговой сверке оставался зелёной стандартной иконкой. В документированном запросе обновления организации нет поля загрузки аватара. Ручное размещение — **GitHub → Organizations → Clank Mafia → Settings → Upload new picture** под изображением профиля. Файл для загрузки — [avatar.png](avatar.png). [Настройки профиля GitHub](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile#changing-your-organizations-profile-picture) · [Документированные параметры API](https://docs.github.com/en/rest/orgs/orgs#update-an-organization)

После публикации Master публичный API вернул новый README и обе иллюстрации. Все три файла совпали побайтово с локальным комплектом. Графика подготовлена для будущих каналов. Осмотр относится к изображениям и публичным файлам. Отрисовка страницы организации в браузере не проверялась.
